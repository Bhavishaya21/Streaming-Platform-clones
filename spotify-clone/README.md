# Soundify — Spotify UI Clone

A responsive music-platform interface built with **HTML, CSS and vanilla JavaScript**.

### Features
- Desktop sidebar and responsive mobile navigation
- Playlist and quick-access cards
- Search/filter across the music catalogue
- Interactive track selection and persistent player bar
- Play/pause demo control and progress slider
- Responsive album grids
- No build tools or dependencies

### Run
Open `index.html` directly, or use VS Code Live Server.
