# Streaming Platform UI Clones

Two polished, responsive frontend projects built with **HTML, CSS and vanilla JavaScript**.

## Projects

- `netflix-homepage-clone/` — Netflix-inspired streaming homepage with hero banner, content rows, search, genre filters and a details modal.
- `spotify-clone/` — Spotify-inspired music dashboard with sidebar navigation, playlists, search, play controls, progress bar and responsive mobile layout.

## Run locally

No build tools or dependencies are required.

1. Download or clone the repository.
2. Open either project's `index.html` in a browser.
3. For the best development experience, use VS Code + Live Server.

## GitHub Pages

Either project can be deployed as a static GitHub Pages site. Set the Pages source to the selected project directory if using a deployment workflow, or publish each project as its own repository.

> These are educational UI recreations inspired by popular streaming services. They are not affiliated with Netflix or Spotify.
